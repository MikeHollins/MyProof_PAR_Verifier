# Provider mutation matrix

This matrix is keyed to the current `PublicRecordEvidenceInputSchema` and its
nested schemas in `src/contracts/input.ts`. The
`producer-omit-wire.json` fixture is the exact PAR-produced `audit=omit`
artifact, copied byte-for-byte from PAR's checked-in fixture. Its producer-file
SHA-256 is
`4b765d27c75606c03da3fdd4d47fa2605e1f2117ebb96a97076ca453cb78fa88`; the
compact Express JSON wire (`JSON.stringify(JSON.parse(raw))`) SHA-256 is
`ff7043feb3cf7c646adce0695468d6d2978a402474599198e4335de4e7483404`.
The provider hash test records both representations; the end-to-end provider
test is the single positive semantic-preservation check. Do not canonicalize,
reserialize, or mutate the producer fixture itself.

## Equality gate

| Gate                | Source of truth                           | Required assertion                                                                                                                                        | Expected result |
| ------------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- |
| Raw artifact        | PAR handler output plus PAR-supplied hash | Fixture bytes and both recorded SHA-256 values are equal; no local reconstruction                                                                         | PASS            |
| Bundle preservation | `PublicVerificationBundleInputSchema`     | Provider envelope `bundle` retains every producer field, including `statusCheck`, `provenance`, `assurance`, `audit: null`, `checks`, and nested metadata | PASS            |
| Envelope shape      | `PublicRecordEvidenceInputSchema`         | Provider output has only the shared envelope keys and exact canonical `status_url`                                                                        | PASS            |

## Nonproducer-field injection gate

Add one field named `__provider_mutation` at each strict-object path below,
without changing any producer field. Every injection must reject with
`ParProviderError.code === "INVALID_RESPONSE"`.

| Strict-object path                                                 |
| ------------------------------------------------------------------ |
| `PublicRecordEvidenceInputSchema`                                  |
| `PublicVerificationBundleInputSchema`                              |
| `PublicAssetRecordInputSchema`                                     |
| `PublicAssetRecordInputSchema.verificationMetadata` (when present) |
| `PublicAssetRecordInputSchema.status` (when present)               |
| `PublicAssetRecordInputSchema._freshness` (when present)           |
| `ReceiptEvidenceInputSchema`                                       |
| `ReceiptEvidenceInputSchema.publicJwk` (when present)              |
| `ReceiptEvidenceInputSchema.header` (when present)                 |
| `ReceiptEvidenceInputSchema.claims`                                |
| `ReceiptClaimsInputSchema.status_ref` (when present)               |
| `StatusCheckInputSchema`                                           |
| `ProvenanceInputSchema`                                            |
| `BundleChecksInputSchema`                                          |
| `ReceiptJwksInputSchema`                                           |
| `ReceiptJwkInputSchema` (each key)                                 |
| `StatusCredentialEvidenceInputSchema` (each present copy)          |
| `PublicAssuranceEvidenceInputSchema` (when non-null)               |
| `PublicAssurancePayloadInputSchema` (when non-null)                |
| `AssuranceOrderedPredicateSchema` (each item, when non-null)       |

The provider must not copy an injected field into the shared envelope. The
bounded predicate record is the sole intentional producer-defined map and is
validated by its own finite key/value limits.
